# Idle policy

A certain background wake holds the push until delivery or user return; a known
wake before cache expiry drops the warning. Report only work that wakes the
session when it ends. A subagent waiting for permission does not qualify.

The launcher closes an open stretch on primary reopen: exit hooks may not run
when a terminal is killed, while adapters cannot distinguish reload from resume.
TTL detection reads the chat's launch-recorded native store, since an agent can
change directory without moving its transcript.

KB `decisions/idle-notifications.md` records the policy and hosting choices.
